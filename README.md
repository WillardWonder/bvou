# YOU University · Mental Game Lab

Interactive mental-performance training for **Merrill Bluejays Wrestling**, built as an independent companion to *WINNING STATE Wrestling* by Steve Knight (not affiliated with or endorsed by the author or publisher).

- `index.html`, `app.js`, `data.js`: the static site (no build step, no backend)
- `YOU_University_Mental_Game_Workbook.pdf`: the printable 35-page workbook
- All athlete answers stay in each athlete's own browser (localStorage). Nothing is uploaded.

Team language follows the Merrill Wrestling Terms Compendium v1.0. Book concepts are paraphrased from the publisher's own materials and labeled with source keys. See the Coaches page.
